# Task-5-EDA-Titanic-Analysis
Exploratory Data Analysis on the Titanic dataset using Python, Pandas, Matplotlib, and Seaborn.

## 📌 Objective
The objective of this project is to perform Exploratory Data Analysis (EDA) on the Titanic dataset and identify patterns, trends, and relationships using Python visualization libraries.

---

## 🛠 Tools and Libraries Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

---

## 📂 Dataset
- Titanic Dataset
- Total Records: 891
- Total Features: 12

---

## 🔍 Analysis Performed
- Data Loading and Inspection
- Missing Value Analysis
- Statistical Summary
- Age Distribution Analysis
- Survival Analysis
- Gender Distribution Analysis
- Passenger Class Analysis
- Correlation Analysis
- Pairplot Visualization

---

## 📊 Visualizations
- Age Distribution Histogram
- Survival Count Plot
- Gender Distribution Plot
- Passenger Class Distribution
- Age Boxplot
- Correlation Heatmap
- Pairplot

---

## 📈 Key Findings
- Most passengers were between 20 and 40 years old.
- More passengers died than survived.
- Male passengers were more than female passengers.
- Most passengers traveled in 3rd class.
- The Age and Cabin columns contain missing values.
- First-class passengers had better survival rates.
- Higher fares were associated with higher survival chances.
- Passenger class and fare show a strong relationship.
